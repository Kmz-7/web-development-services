# Web Development Services

**Frontend Prototype | Personal Project | Work in Progress**

A personal frontend project built to explore modern web design, interactive interfaces, and animation techniques using React, Next.js, TypeScript, Tailwind CSS, and Motion.

This repository represents the **initial design and experimentation phase of a future commercial website**, where I plan to showcase and offer my web development services to businesses and individual clients.

The goal is to test different layouts, visual styles, animations, and user experiences before developing and launching the final product.

> **Disclaimer:** This project is a prototype and is not currently operating as a commercial service. All business information, pricing, statistics, service offerings, template previews, and other commercial content displayed on the website are fictional or illustrative. Forms and actions may be incomplete or simulated.

## Project Motivation

Earlier in my career, I worked primarily with HTML, CSS, JavaScript, and Bootstrap to develop websites for businesses.

As I gained more experience with React and modern frontend technologies, I wanted to explore a different approach to building interfaces, with greater flexibility in layout design, animations, reusable components, and user interactions.

I also have a long-term goal of creating my own website to offer freelance web development services.

Rather than immediately building the final commercial platform, I decided to start with a prototype where I could freely experiment, evaluate design ideas, and improve my frontend development skills.

This repository is the result of that process.

## Technologies

- **Next.js** — React framework and application structure.
- **React** — Component-based user interface development.
- **TypeScript** — Static typing and improved code maintainability.
- **Tailwind CSS** — Responsive layouts and custom styling.
- **Motion** — Interactive animations, transitions, and visual effects.
- **shadcn/ui and Radix UI** — Reusable and accessible UI components.
- **Lucide React** — Interface icons.

## Implemented Features

The prototype currently includes:

- Responsive landing page structure.
- Reusable UI components.
- Interactive hero section with mouse-driven visual effects.
- Animated elements and smooth transitions.
- Layout showcase with interactive hover previews.
- Navigation adapted for desktop and mobile devices.
- Portuguese and English language selection.
- Language preference persistence using localStorage.
- Reduced-motion support for accessibility preferences.
- Contact form interface with field validation and simulated submission.

Some features are experimental and may be modified, replaced, or removed during future development.

## Running Locally

**Requirements:**

- Node.js
- npm

Clone the repository:

```bash
git clone https://github.com/Kmz-7/web-development-services.git
```

Navigate to the project directory:

```bash
cd web-development-services
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.
